# StackBroom

**Know what's running. Reclaim what's idle.**

StackBroom is a Windows-first, read-only resource inspector for local development
environments. It reports what Windows processes, Docker and WSL2 are using so a
developer can decide for themselves what to clean up.

> **Status:** repository baseline. The v0.1 read-only implementation is being
> developed on `feat/v0.1-read-only-discovery`.
